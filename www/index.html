tpool-c

A small web server in C: one acceptor thread, a mutex-protected request queue, and a pool of worker threads.

Endpoints

  • /hello: tiny response, shows raw per-request overhead
  • /sleep?ms=200: blocks the handling thread, like a slow database or API call
  • /cpu?n=50000000: CPU-bound work
  • /stats: live counters (requests, queue wait, queue depth)

Open /sleep?ms=3000 in two tabs at once. On server_st the second tab waits for the first to finish; on server_mt both come back after about 3 seconds.
